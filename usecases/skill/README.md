# Skill Lifecycle use cases

Concrete bindings of [Agent-first Skill Lifecycle Architecture](../../docs/agent-first-skill-lifecycle.md). These pages show how imported or relationship-formed procedural artifacts behaved in practice, which lifecycle records existed, and which governance gaps remained.

A product-specific skill may be useful evidence without becoming a dependency or recommendation. The protocol carries the portable rules; each use case keeps the real artifact and environment visible enough to audit the mapping.

## Current use cases

- [Kiro Taobao Native](kiro-taobao-native.md) — evidence `field-tested`, conformance `mapped`; a pre-protocol imported commerce skill with repeated private real-environment activations, a runtime fallback lesson, and unrecorded version drift, but no recorded adoption, evaluation, or rollback lifecycle.

This is the first documented binding evidence for the Skill Lifecycle protocol. It does not define the protocol by itself and does not establish any `skill:L0+` conformance.
